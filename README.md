## ೨. ತಂತ್ರಜ್ಞಾನ ವಾಸ್ತುಶಿಲ್ಪ (Technology Architecture)

- **ಫ್ರಂಟ್‌ಎಂಡ್ (Frontend)**: Next.js 14 (App Router) + React 18 + TypeScript
- **ವಿನ್ಯಾಸ (UI / Styling)**: Tailwind CSS (ಪೋಸ್ಟರ್‌ನ ಕೆಂಪು, ಚಿನ್ನದ ಹೊಳಪು, ಕಡು ನೀಲಿ ಹಾಗೂ ಹಸಿರು ಬಣ್ಣಗಳ ಕ್ರೀಡಾ ಥೀಮ್)
- **ಕನ್ನಡ ಫಾಂಟ್ (Typography)**: Google Fonts `Noto Sans Kannada`
- **ಹಿನ್ನೆಲೆ (Backend)**: Next.js Server Components, Server Actions & Edge API Routes
- **ಡೇಟಾಬೇಸ್ (Database)**: Prisma ORM (ಪ್ರಸ್ತುತ SQLite `dev.db`, PostgreSQL / MySQL ಗೆ ಸುಲಭವಾಗಿ ಬದಲಾಯಿಸಬಹುದು)
- **ಭಾವಚಿತ್ರ ಸಂಗ್ರಹಣೆ (Photo Storage)**: ಶಾಶ್ವತ ಸ್ಥಳೀಯ ಫೈಲ್ ಸಂಗ್ರಹಣೆ `/uploads` ಹಾಗೂ ಸುರಕ್ಷಿತ HTTP ಸರ್ವಿಂಗ್ API
- **ಪಾವತಿ ಗೇಟ್‌ವೇ (Payment Gateway)**: Razorpay API (HMAC-SHA256 ಸರ್ವರ್ ಸೈಡ್ ಸಿಗ್ನೇಚರ್ ಪರಿಶೀಲನೆ ಮತ್ತು ವೆಬ್‌ಹುಕ್ ಬೆಂಬಲ)
- **ಕೋಡ್ ಉತ್ಪಾದನೆ**: ಡೇಟಾಬೇಸ್ ಸೀಕ್ವೆನ್ಸ್ ವಹಿವಾಟಿನ ಮೂಲಕ ಪರಮಾಣು (Atomic) ಅನನ್ಯ ಕೋಡ್ ಉತ್ಪಾದನೆ (`SBK26-000001`)
- **ಭದ್ರತೆ**: Bcrypt ಪಾಸ್‌ವರ್ಡ್ ಹ್ಯಾಶಿಂಗ್, JWT ಸುರಕ್ಷಿತ ಸೆಷನ್ ಕುಕೀಸ್, ರೇಟ್ ಲಿಮಿಟಿಂಗ್ (Rate Limiting) ಮತ್ತು ಖಾತೆ ಲಾಕ್‌ಔಟ್

## ೩. ಜಾಲತಾಣದ ಪುಟಗಳ ರಚನೆ (Website Pages)

1. **ಮುಖಪುಟ (`/`)** — ಪೋಸ್ಟರ್, ಬಹುಮಾನ ವಿವರ, ನೇರ ನೋಂದಣಿ ಬಟನ್, ಸಾಮರ್ಥ್ಯ ಸೂಚಕ, ನಿಯಮಗಳು, ಆಯೋಜಕರ ಸಂಪರ್ಕ
2. **ಆಟಗಾರರ ನೋಂದಣಿ (`/register`)** — ಪೂರ್ಣ ಹೆಸರು, ಮೊಬೈಲ್ ಸಂಖ್ಯೆ, ವಿಳಾಸ, ವಿಭಾಗ (ಬ್ಯಾಟ್ಸ್ಮನ್/ಬೌಲರ್/ಆಲ್ರೌಂಡರ್), ಭಾವಚಿತ್ರ ಅಪ್ಲೋಡ್
3. **ನೋಂದಣಿ ಶುಲ್ಕ ಪಾವತಿ (`/payment`)** — ಆಟಗಾರರ ಸಾರಾಂಶ, Razorpay ಚೆಕ್‌ಔಟ್, ಸರ್ವರ್ ಸೈಡ್ ಸಿಗ್ನೇಚರ್ ದೃಢೀಕರಣ
4. **ನೋಂದಣಿ ಯಶಸ್ವಿಯಾಗಿದೆ (`/success`)** — ಅಭಿನಂದನೆ ಪರದೆ, ಅನನ್ಯ ನೋಂದಣಿ ಕೋಡ್ (`SBK26-XXXXXX`), ಕೋಡ್ ಕಾಪಿ ಮತ್ತು ಪ್ರಿಂಟ್/PDF ಆಯ್ಕೆ
5. **ನೋಂದಣಿ ಸ್ಥಿತಿ ಪರಿಶೀಲಿಸಿ (`/status`)** — ನೋಂದಣಿ ಕೋಡ್ ಮತ್ತು ಮೊಬೈಲ್ ಮೂಲಕ ಆಯ್ಕೆಯ ಫಲಿತಾಂಶ ವೀಕ್ಷಣೆ
6. **ಪಂದ್ಯಾವಳಿ ಮಾಹಿತಿ (`/info`)** — ಸಂಪೂರ್ಣ ನಿಯಮಗಳು, ಸೌಲಭ್ಯಗಳು ಮತ್ತು ಪೋಸ್ಟರ್ ಮುನ್ನೋಟ
7. **ಸಂಪರ್ಕಿಸಿ (`/contact`)** — ಆಯೋಜಕರಿಗೆ ನೇರ ಕರೆ ಮತ್ತು WhatsApp ಸಂದೇಶ ಬಟನ್‌ಗಳು
8. **ನಿರ್ವಾಹಕರ ಲಾಗಿನ್ (`/admin/login`)** — ಪಾಸ್‌ವರ್ಡ್ ಮರೆಮಾಚುವಿಕೆ, ವಿಫಲ ಯತ್ನಗಳ ಲಾಕ್‌ಔಟ್, ಸುರಕ್ಷಿತ ಪ್ರವೇಶ
9. **ಪಾಸ್‌ವರ್ಡ್ ಬದಲಾವಣೆ (`/admin/change-password`)** — ಮೊದಲ ಬಾರಿಯ ಲಾಗಿನ್‌ನಲ್ಲಿ ಕಡ್ಡಾಯ ಪಾಸ್‌ವರ್ಡ್ ಬದಲಾವಣೆ
10. **ನಿರ್ವಾಹಕ ಫಲಕ (`/admin/dashboard`)** — ಮುಖ್ಯ ನಿರ್ವಾಹಕ (Supervisor) ಮತ್ತು ಸಾಮಾನ್ಯ ನಿರ್ವಾಹಕರ (Normal Admin) ಪಾತ್ರಾಧಾರಿತ ಫಲಕ

## ೬. Razorpay ಪಾವತಿ ಗೇಟ್‌ವೇ ಕಾನ್ಫಿಗರೇಶನ್ (Payment Gateway Setup)

ನೈಜ ಆನ್‌ಲೈನ್ ಪಾವತಿಗಳನ್ನು ಸ್ವೀಕರಿಸಲು, [Razorpay Dashboard](https://dashboard.razorpay.com) ನಿಂದ ನಿಮ್ಮ API ಕೀಗಳನ್ನು ಪಡೆದು `.env` ಫೈಲ್‌ನಲ್ಲಿ ನಮೂದಿಸಿ:

```env
RAZORPAY_KEY_ID="rzp_test_YourKeyIdHere"
RAZORPAY_KEY_SECRET="YourSecretKeyHere"
RAZORPAY_WEBHOOK_SECRET="YourWebhookSecretHere"
NEXT_PUBLIC_RAZORPAY_KEY_ID="rzp_test_YourKeyIdHere"
```

1. **ಪರೀಕ್ಷಾರ್ಥ ಪಾವತಿ (Test Mode)**: Razorpay ಟೆಸ್ಟ್ ಕೀಗಳನ್ನು ಬಳಸಿದಾಗ, UPI (Google Pay, PhonePe, Paytm), ನೆಟ್ ಬ್ಯಾಂಕಿಂಗ್ ಮತ್ತು ಕಾರ್ಡ್‌ಗಳ ಪರೀಕ್ಷಾರ್ಥ ಪಾವತಿ ಲಭ್ಯವಿರುತ್ತದೆ.
2. **ಲೈವ್ ಪಾವತಿ (Live Mode)**: ಬ್ಯಾಂಕ್ ಕೆವೈಸಿ ಪೂರ್ಣಗೊಂಡ ನಂತರ ಲೈವ್ ಕೀಗಳನ್ನು ಹಾಕಿದರೆ ನೇರವಾಗಿ ಪಂದ್ಯಾವಳಿ ಸಮಿತಿಯ ಬ್ಯಾಂಕ್ ಖಾತೆಗೆ ಹಣ ಜಮೆಯಾಗುತ್ತದೆ.
3. **ವೆಬ್‌ಹುಕ್ (Webhook)**: Razorpay ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ Webhooks ಸೆಟ್ಟಿಂಗ್ಸ್‌ಗೆ ಹೋಗಿ `https://yourdomain.com/api/payment/webhook` ವಿಳಾಸವನ್ನು ಸೇರಿಸಿ ಮತ್ತು `payment.captured` ಈವೆಂಟ್ ಅನ್ನು ಆಯ್ಕೆ ಮಾಡಿ.

## ೮. ಡೇಟಾಬೇಸ್ ಬ್ಯಾಕಪ್ ಮತ್ತು ಮರುಪಡೆಯುವಿಕೆ (Backup & Recovery)

1. **ಬ್ಯಾಕಪ್ ಮಾಡಲು**:
   - SQLite ಬಳಸುತ್ತಿದ್ದರೆ, `prisma/dev.db` ಫೈಲ್ ಮತ್ತು `uploads/` ಫೋಲ್ಡರ್ ಅನ್ನು ಕ್ಲೌಡ್ ಸ್ಟೋರೇಜ್‌ಗೆ ಬ್ಯಾಕಪ್ ಮಾಡಿಕೊಳ್ಳಿ.
   ```bash
   # Windows PowerShell Backup Script
   Copy-Item "prisma\dev.db" "backup\dev_$(Get-Date -Format 'yyyyMMdd_HHmmss').db"
   Copy-Item "uploads" "backup\uploads_$(Get-Date -Format 'yyyyMMdd_HHmmss')" -Recurse
   ```
2. **PostgreSQL / MySQL ಗೆ ಬದಲಾವಣೆ**:
   `.env` ನಲ್ಲಿ `DATABASE_URL="postgresql://user:pass@host:5432/dbname"` ಎಂದು ಬದಲಾಯಿಸಿ `prisma/schema.prisma` ನಲ್ಲಿ `provider = "postgresql"` ಎಂದು ನಮೂದಿಸಿ `npx prisma db push` ಚಲಾಯಿಸಿ.
